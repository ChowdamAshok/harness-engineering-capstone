# Harness Engineering Capstone

This repository contains my completed capstone work for **Harness Engineering with Claude and Claude Code**.

## Projects

### 1. Insurance Claims Intake Agent

**Project:** Build a Claims Intake Agent with a stop_reason-Driven Loop

Demonstrates stop_reason-driven agent loops, dynamic tool use, structured tool errors, claim fact recording, classification, escalation, routing, and trace evidence.

Location: `system-1-claims/`

### 2. Retail Support Context Strategy

**Project:** Engineer a Long-Conversation Context Strategy for a Retail Support Copilot

Demonstrates context assembly, token budgeting, context pruning, section-specific compression, and evaluation.

Location: `system-2-retail/`

### 3. Claude Code Multi-Surface Monorepo Configuration

**Project:** Configure Claude Code for a Multi-Surface Monorepo Team

Demonstrates project-scoped rules, path-scoped rules, commands, skills, forked sub-agent execution, and read-only tool restrictions.

Location: `system-3-claude-config/`

### 4. Multi-Shift Quality Monitoring

**Project:** Build a Multi-Shift Quality Monitoring System with Claude Orchestration

Demonstrates tiered state, warm database state, shift orchestration, crash recovery, and forked scratchpad workflows.

Location: `system-4-shift-monitor/`
